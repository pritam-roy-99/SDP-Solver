# Contributing

Please open an issue describing the mathematical scenario and expected benchmark before changing the word algebra or SDP formulation. Include the hierarchy level, solver, solver version, tolerances, status, and a reproducible minimal example when reporting numerical problems.

Run `python -m pytest -q` before submitting a change. Never interpret an `optimal_inaccurate` status as a certified bound. Please cite the original NPA and BFF papers when using their frameworks.
